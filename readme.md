# boss-job-helper
针对 BOSS 直聘网页端的 AI 辅助脚本，支持职位投递、回复HR等核心场景，帮助求职者高效筛选岗位、提升求职沟通效率。
## 核心功能
* 智能自动投递
    -  精准筛选投递：支持自定义职位排除关键词（如"外包"、"大厂"）、工作地点关键词（如"杭州"），脚本自动过滤不符合条件的岗位，仅对匹配的职位执行投递操作。
    - AI 匹配度校验：集成 AI 能力分析简历与职位描述的匹配度，可自定义匹配阈值（默认 60 分），仅对达到阈值的岗位发起沟通，提升投递精准度。
    - 自动化操作：脚本自动扫描职位列表，逐个点击"立即沟通"按钮，全程无需人工干预，大幅提升投递效率。
* 智能回复
    - 自定义问答库：预设常见 HR 问题（如离职时间、到岗时间、薪资期望等）及对应答案，AI 可精准匹配问题并自动回复，避免重复手动输入。
    - AI 判断发简历：智能分析 HR 聊天内容，自动判断是否需要发送简历，满足条件时自动点击 “发简历” 按钮，简化沟通流程。
## 具体实现

* 纯前端原生 JS：基于原生 JavaScript 开发，无框架依赖，适配 BOSS 直聘网页端 DOM 结构，无需后端服务。
* 无逆向/抓包：仅通过前端 DOM 解析提取职位名称、薪资、地址、聊天内容等信息，规避接口调用的合规风险。
* 多AI接口适配：支持火山引擎、OpenAI、DeepSeek 等主流 AI 接口，可自定义 API 地址、密钥、模型类型。
* 鲁棒性设计：内置元素等待、延迟操作、异常捕获机制，适配页面加载延迟、DOM 结构变更等场景，提升稳定性。
核心类说明

|类名|	核心功能|
|--|--|
|LocalStorageManager |	本地存储管理，处理配置、交互记录的持久化|
|DOMCache |	DOM 元素缓存，减少重复查询，提升性能|
|DOMUtils	|DOM 操作工具，包含元素等待、模拟点击、延迟操作等|
|AIService	|AI 服务封装，处理匹配度打分、问答匹配、简历发送判断|
|JobsHandler|职位列表处理，负责筛选、点击、AI 匹配度校验|
|HRHandler|	聊天交互处理，监听消息、匹配问答、自动发消息/简历|
|UIManager|	界面管理，创建操作面板、迷你图标、日志展示、通知提示|
## 使用教程
1. 第一步：安装浏览器插件
推荐使用 **ScriptCat（脚本猫）** 或 **Tampermonkey（油猴）**。
安装后需开启以下权限：
* 开启拓展程序的"开发者模式"；
* 允许插件"运行用户脚本"；
2. 第二步：开始使用
    - 登陆Boss直聘
    - 配置 AI 接口和上传简历文本内容
3. 进阶配置
    - 增加自定义问答库：示例[{"question":"到岗时间","answer":"一周内到岗"}]
    - 调整匹配阈值：修改本地存储 matchThreshold 值（默认 60），调整 AI 简历匹配的最低分数；
    - 自定义 AI 角色：自定义 AI 回复的人设、语气、内容规则；
    - 过滤猎头/非活跃 HR：配置是否排除猎头、筛选 HR 活跃状态，精准定位目标沟通对象。
